# Security policy

Nodrelay gives MCP clients file and command access to your devices, so please report vulnerabilities privately.

- Use **Report a vulnerability** on this repository's **Security** tab (GitHub private vulnerability reporting).
- Do not open a public issue for a security problem, and do not include live install codes, tokens or Portal addresses in a report.

Please describe the affected component (management console, device service, installer or packaging), the version or commit, and the steps to reproduce. You will get an acknowledgement as soon as the report is reviewed.

Only the latest release and the `main` branch receive security fixes during the preview.
